## Websites

### VELORA — café ordering from the table
**Live:** https://oblivra94-lang.github.io/portfolio/velora/

Guests scan the QR code on their table, browse the café's menu, order, pay at the counter and follow the order until it is ready. Staff run orders, payments, menus, tables and QR codes from a dashboard. The home page opens with an interactive 3D drink showcase.

- **Built with:** React, Vite, Tailwind CSS, three.js
- **Try it:** use the **Live demo** tab on the right of the page, then choose *Order from a table* or *Staff dashboard*. The demo staff sign-in is `owner@velora.demo` / `velora-demo`.
- In this demo, sample cafés, menus and orders stand in for the Django REST back end, so everything works without a server.

### Persona/16 — MBTI personality website
**Live:** https://oblivra94-lang.github.io/portfolio/persona16/

A 16-question personality test on a seven-point scale. Visitors sign up, take the test, get their four-letter type with how strongly they lean on each axis, and keep every result. It also has an art gallery, flip cards for the four axes and a 3D ring of all sixteen type cards.

- **Built with:** PHP, MySQL, JavaScript, CSS
- **Team of three:** Altamash Ahmed (concept and visual design), Kevin Manani (front end and 3D interactions), Ravi Dhangria (PHP, database and test logic)
- The original runs on PHP and MySQL. The live version here runs the same pages in the browser, so accounts and results are saved on the visitor's device.
